## 🛠️ Markdown Note Format Standard

Every DSA markdown note adheres to the standard layout:
1. **Title & Purpose Quote:** Target test bands and language agnostic specifications.
2. **Table of Contents:** Linked markdown anchor headings.
3. **Core Concepts & Mental Model:** Invariants, visual representations, memory diagrams.
4. **Complexity Reference Table:** Big-O asymptotic bounds ($\mathcal{O}(1)$, $\mathcal{O}(\log N)$, $\mathcal{O}(N)$, etc.).
5. **Canonical Algorithmic Templates:** Production-ready C++ / Java / Python implementations.
6. **Placement Practice Problems:** Problem statement, approach, step-by-step logic, complexity analysis.
7. **Corner Cases & Traps:** GitHub alert blocks (`> [!WARNING]`, `> [!IMPORTANT]`, `> [!TIP]`).
